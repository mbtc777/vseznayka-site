# Всезнайка — AI-консультант по 1С

Лендинг сервиса: [https://mbtc777.github.io/vseznayka/](https://mbtc777.github.io/vseznayka/)

**Что это.** AI-консультант по 1С: метаданные типовых конфигураций (КА 2.5, УТ, БП, ЗУП, ERP, УНФ, ДО),
база знаний ИТС, разбор документов и проводок, первая линия поддержки с эскалацией человеку.

**Принципы работы.** Изоляция клиентов · доступ к базе только на чтение · шифрование (AES-256 / TLS 1.3) ·
минимальные привилегии · полный аудит действий · обфускация ПДн перед отправкой в модель ·
ответ со ссылкой на источник · эскалация вместо догадки.

**Тарифы.** Базовый (типовые конфигурации + ИТС) · Проф (read-only доступ к базе клиента) ·
Корп (индивидуальный агент, кастомные интеграции, SLA 1 ч).
